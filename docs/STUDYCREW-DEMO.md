# 可重复演示脚本

演示仅使用合成课程和 `evals/fixtures/` 图片。先按 `TECH.zh-CN.md` 准备 Node 24、Python 3.12 与依赖，运行 `npm run electron:build`，再启动桌面应用。真实模型配置使用用户确认的提供方和 endpoint，通过应用凭据保险库输入；不要在录屏中显示密钥。

1. **创建课程群。** 新建“面试演示：线性代数”，使用项目内独立工作目录，开启知识/规划/教练。说明 Coordinator 和 Verifier 是必需角色。
2. **生成可执行计划。** 今日页添加课程、考试、可用时间。先给不足的时段，观察冲突；增加时段后重排；延期或跳过一个任务；导出 ICS。导出文件中的事件应与页面排期一致。
3. **反馈与复习。** 录入一道合成题，提交错误答案再答对，观察解析、掌握度与下次复习；不要声称简单答案比对就是通用自动阅卷。
4. **记忆治理。** 保存推断偏好，确认其进入候选；确认指定版本后查看召回；编辑、删除，再尝试重新保存同句，验证墓碑保护。切换其他群组确认不可见。
5. **资料到证据。** 导入合成文本和图像。先演示无需模型的检索，再对图像选择受批视觉处理。审批明确显示来源与版本。显示答案和引用，点开原文位置；替换来源后旧引用应过期。
6. **任务完整链。** 群聊展开受保护任务，输入具体任务，检查提案，批准当前版本，观察 Worker/工具/Verifier 与结果。取消另一个任务；重新启动后查看历史，确认没有自动重放付费请求。
7. **评测与来源。** 打开固定数据集、实际执行报告、失败样例和账本。分别说明本地组件、模拟 HTTP、真实模型和桌面验证。最后说明 Knowe 的 MIT 归属与本分叉新增内容。

每次演示使用新群组名，既有用户数据不清空。某功能报告 unsupported、partial、paused 或错误时如实展示并解释。最终交付报告未标记实际验证通过的步骤，不能作为“演示已跑通”的证据。
