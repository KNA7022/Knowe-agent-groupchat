所有请求共用 [账本](../evals/runs/paid-ledger.jsonl)。已知用量合计 **32,125 输入、3,222 输出 tokens**，按官方原价 **¥0.501492**；另一次旧解析器失败的用量未知，永久保留其完整上界 **¥0.171648**。本次总费用保守上界 **¥0.673140 / ¥50**，不是账户实付账单。包含所有有费用的失败尝试、120 场景及额外 11 次产品/协议请求，未充值。见 [最终费用汇总](../evals/runs/cost-final.json)。密钥未写入项目、日志和报告，临时密钥会话已关闭。

旧 `rag-live.json` 在已取得用量并结算后发生响应解压传递失败，其旧状态标签不准确；最终账本按已知费用计入一次。旧 UI 探针曾因状态大小写等待失败，模型调用仍计费，修复驱动后完整 UI 探针通过。保留这些失败以避免只呈现成功尝试。

## 仍需如实说明的风险

1. 引用检查证明 chunk、页码、版本和精确原文成员关系，不证明模型结论的语义蕴涵；相关结果保留 PARTIAL。
2. 新受保护群组内容采用加密真源和无正文历史引用；旧私聊/旧历史路径不在“所有聊天都已加密”的声明范围内。无主密钥时受保护持久化拒绝执行。
3. Office 转换依赖本机 Office，转换时有临时明文，正常清理已实现，崩溃后的临时文件清理未验证。
4. 本机安装成功不代表无 Office/无相关系统运行库的干净机器成功。完整退出后的定时通知不支持，OS 实际显示和外部日历客户端导入更新未验收。
5. 120 场景不是大规模真实学习用户实验；E5 排名质量、开放题教学正确性和真实教育效果仍需独立研究。确定性练习不是通用 AI 判卷。
