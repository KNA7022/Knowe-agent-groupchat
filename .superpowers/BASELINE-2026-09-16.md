### 4.3 复审自身的一处过度解读（我也要指出）

复审 I-R1 用"`extra_body` 可覆盖最终 body"暗示 DLP 边界可绕过，**这是过强的读法**：`_serialized_request`（`commercial_gateway.py:2017`）把整个 `extra_body` 也纳入扫描字符串，内容类 DLP 并未失效。真正失配的是**授权元数据与实际发送请求脱节**（registry 校验 `self.model`，线上 `body["model"]` 可被覆盖）+ 预算估算基于旧 messages。修复方向应是"冻结请求字节"，不是"加固 body 重建"。

### 4.4 Round 2 的真实起点

工作树里唯一的 Round 2 产物是未跟踪红测 `backend/tests/test_task2_round2_mcp_security.py`，**当前失败**：

```
TypeError: McpRegistry.__init__() got an unexpected keyword argument 'http_client_factory'
1 failed in 0.51s
```

它与现实现的差距**不是加一个 kwarg**，而是 4 处 public API 变更：`McpRegistry(*, http_client_factory)`、`handshake(server_id)` 单参化、新增 `close()`、以及 **capability 驱动的 discovery**（`allowed_resources=()` 时不得发 `resources/list`；否则测试中 mock handler 对 `resources/list` 会 KeyError）。这个红测形状正确，可作为 C-R2 的验收标准。

## 6. 取舍建议

### 建议 A：先修"能交付"，再谈"功能"（推荐）

**理由**：简历项目的杀手问题是"能不能跑起来给人看"。当前连安装包都产不出来，"完成了 RAG"在面试中无法演示。

1. **阶段 0（入场券，必须最先做）**
   - 把 Node 切回 24.x（或明确记录本机偏离），让 `preflight` 与前端 563 用例回到全绿。
   - 修打包链四项：`build/installer.nsh`、spec 的 `dotenv`、spec 品牌/版本、PyInstaller 驱动脚本。**产出第一个能安装的 NSIS 包**。
   - 这一步独立于所有安全发现，且立刻解锁"可演示"。

2. **阶段 1（Task 2 Round 2 收口）**
   - 必修：C-R1、I-R1、I-R6、I-R8、I-R4。
   - 接口形状（成本低、防未来重演）：I-R2 的 executor 绑定。
   - 可降级为已知限制（须显式声明 + 补测试）：I-R3b、I-R7。
   - 同时**更正报告 §4.2 的三处失实**——这比代码修复更重要，因为失实声明会污染后续所有判断。

3. **阶段 2（Task 3 加密 RAG 竖切片）**
   - 先做**一条端到端竖切片**（PDF → 解析 → chunk → 加密 → BM25+向量 → 检索 → 精确引用 → 预览定位），而不是铺满 7 种格式。
   - 理由：竖切片是简历/面试最有效的证据，且能提前暴露"加密删除闭环"与"PyInstaller 排除 numpy"这两个真正的难点。

4. **阶段 3（Task 4/5）**
   - Task 4 必须先复用上游候选/晋升/墓碑语义，不要另起一套。
   - Task 5 的评测底座与 Task 6 的 ≥120 场景合并设计。

### 建议 B：先做"简历材料 + 一个可演示竖切片"，安全与 RAG 只做坦诚标注

适合时间紧、优先投递的情况。代价：简历上"多模态 RAG""Mem0 记忆层"只能写成规划中，不能声称完成；且 Task 2 的 2 Critical 会以"已知未修"状态进入面试问题范围。**不建议在没有诚实标注的情况下走这条**。

### 建议 C：直接跳到 Task 3 RAG

**不建议。** C-R1/I-R1 是设计级缺陷，一旦 RAG 引入 embedding/vision provider 调用点，会把这些缺口以更多调用方的形式放大（且 `production_model_capability_registry` 目前只注册 `{"chat","stream","tools"}`，**没有 embedding/vision/rerank 的建模挂点**）。

### 无论走哪条，两条不可妥协

1. **测试基线可信**：确认 pytest 能写 TEMP（否则 404 个假 error 会掩盖真实回归）；确认 Node 版本与基线一致。
