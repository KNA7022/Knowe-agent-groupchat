# Local capability-pack manager — prepared slice, not yet dispatched

## Scope

Implement only the user-operated capability-pack installation lifecycle, authenticated settings API and small existing-style UI. Read local-model-pack-design.md completely for verified upstream facts, containment/network requirements and current seams. Model execution, E5/USearch integration, OCR preprocessing and optional cloud authorization are later slices. Do not describe metadata verification as successful inference. Controller supplies BASE when this slice starts.

User requirements remain local PP-OCRv6 Small ONNX (no PaddlePaddle), default multilingual-e5-small INT8 ONNX, optional BGE-M3, Node24/Python3.12/Windowsx64. Preserve source privacy, MIT upstream attribution and model notices; no accounts/PIN. Preserve skills/. UTF8/apply_patch, one production implementer, no child agents.

## Deliverable

- A bundled reviewed catalog is the trust root. Request accepts only known pack/version/operation, never arbitrary URL/path/script/custom operator. Complete manifests bind fixed official revision, every artifact path/byte count/SHA256 and licence/notice, format/runtime/preprocess identity and status. The design's published hashes alone are not a complete activation manifest. Metadata can be completed from primary official sources; never invent hashes or licence files. Unknown/incomplete compatibility stays visible but not ready.
- Reuse authenticated local server, origin/token policy and user-owned settings semantics. Installation is not a fabricated Agent execution/permission grant. Expose bounded jobs/status/cancel/install/activate/rollback/remove with opaque operation IDs and consistent idempotent responses.
- Individual pinned files, no archives in this slice. Public model assets live under managed model_packs, never user content. Exclusive opaque staging, streaming size/hash limits, safe Windows paths/reparse checks, exact manifest member allowlist, same-volume immutable version commit and atomic active pointer. Prior version remains usable through failure/cancellation/crash. Record safe cleanup/recovery intent; never broad-delete data root.
- Fixed HTTPS origins/CDN redirects only, no secrets/cookies/user data, bounded hops/time/bytes/concurrency, actual peer-address enforcement against local/private/rebinding routes, no ambient proxy bypass. Reuse existing safe transport if suitable; if actual publisher delivery cannot be bound safely, report concrete issue rather than weaken validation. No automatic install on first search or offline metadata lookup.
- Account staged/retained/active disk bytes and reserve space; locked files/disk full retry bounded and visible. Ready differs from downloaded/installed: activation requires a registered runtime validator; this manager slice must not falsely mark real models ready before the following inference slice. Inert validators only in tests.
- Explicit inference lease contract for later integration: deletion/switch prevents new leases and waits/cancels current work before actual removal; model changes notify index invalidation. Rollback only to intact trusted version. Deleting a pack does not delete source data. Late jobs cannot undo cancellation/removal or activate stale generations.
- UI fits current settings/knowledge design, keyboard operable, status not colour-only. Show version/publisher/licence, exact download and disk measurements, installed versus ready/degraded state, progress/cancel/retry/rollback/remove impact. No provider Key required. BGE is optional and clearly multi-GB, never silently downloaded.
